# AmeriDex Deck Estimator

Public-facing customer deck estimator for AmeriDex Dryspace Decking.
Allows customers to design their deck and receive a rough material cost estimate.

## Files
- `index.html` - Wizard UI (5 steps)
- `thankyou.html` - Post-submission confirmation
- `css/style.css` - AmeriDex design system
- `js/products.js` - Product catalog and pricing data
- `js/estimator.js` - Step navigation and live calculation logic
- `js/validation.js` - Input validation
- `js/lead.js` - Lead capture form submission
